## ✨ মূল ফিচারসমূহ (Key Features)

### 🌐 পাবলিক পোর্টাল (Public Institutional Portal)
1. **ডুয়াল হিরো সেকশন (Image 1 Standard):**
   - বামপাশে ক্যাম্পাসের বাস্তব স্মৃতি ও ইভেন্ট ছবির ইন্টারেক্টিভ অটো-সোয়াইপার।
   - ডানপাশে গোল ফ্রেমে অধ্যক্ষ মহোদয়ের ছবি সম্বলিত অফিসিয়াল বাণী ও ভিউ কার্ড।
2. **লাইভ নোটিশ মারকুই (Breaking Notice Marquee):**
   - জরুরি নোটিশ ও ভর্তি ঘোষণার মসৃণ স্ক্রোলিং ব্যানার।
3. **অনলাইন ভর্তি আবেদন (Online Admission Engine):**
   - সরাসরি ফর্ম পূরণ, রোল ও নম্বর সাবমিশন এবং রিয়েল-টাইম এডমিন ডাটাবেজে রেকর্ড।
4. **শিক্ষকমণ্ডলী ডিরেক্টরি (Faculty & Teachers Directory):**
   - বিভাগভিত্তিক ফিল্টারিং, নাম, পদবী, শিক্ষাগত যোগ্যতা ও যোগাযোগের তথ্য।
5. **পরিচালনা পর্ষদ (Leadership & Governing Body):**
   - চেয়ারম্যান, ম্যানেজিং ডিরেক্টর এবং অধ্যক্ষের পরিচিতি ও প্রোফাইল।
6. **১০০% মোবাইল রেসপনসিভনেস (Zero-Zoom Responsive Design):**
   - ৩২০ পিক্সেল থেকে আল্ট্রা-ওয়াইড মনিটর পর্যন্ত নিখুঁত ডিসপ্লে কোনো অনুভূমিক স্ক্রোলিং ছাড়া।

### ⚙️ সেন্ট্রাল এডমিন কন্ট্রোল প্যানেল (Central CMS Dashboard)
- **ফুল-সাইট ডাইনামিক ম্যানেজমেন্ট:** সাইটের প্রতিটি সেকশন, ব্যানার টেক্সট, লোগো, নোটিশ, শিক্ষক ও পরিচালনা পর্ষদের তথ্য যেকোনো সময় এডমিন প্যানেল থেকে এডিট ও আপডেট করা সম্ভব।
- **ডিভাইস থেকে সরাসরি ফটো আপলোড:** কোনো ক্লাউড স্টোরেজের জটিলতা ছাড়াই কম্পিউটার বা ফোন থেকে যেকোনো হাই-রেজ্যুলেশন ছবি এক ক্লিকে আপলোড ও লাইভ প্রিভিউ।
- **স্বয়ংক্রিয় ইমেজ অপটিমাইজেশন:** ক্লায়েন্ট-সাইড HTML5 Canvas ব্যবহারের মাধ্যমে স্বয়ংক্রিয় কম্প্রেশন (৩০-৫০ KB), যা দ্রুত লোডিং নিশ্চিত করে।
- **রিয়েলটাইম ক্লাউড সিঙ্ক:** Firebase Firestore ও লোকাল ব্যাকআপের মাধ্যমে ডেটা সম্পূর্ণ সুরক্ষিত।
- **ভিজ্যুয়াল সেভ কনফার্মেশন:** পরিবর্তনের সাথে সাথে এমারেল্ড গ্রিন বাটন স্টেট এবং ফ্লোটিং নোটিফিকেশন এলার্ট।

## 🛠️ প্রযুক্তি স্ট্যাক (Tech Stack)

| স্তর | প্রযুক্তি | বিবরণ |
| :--- | :--- | :--- |
| **Frontend Framework** | Next.js 16 (App Router) | SSR/SSG অপটিমাইজড পারফরম্যান্স |
| **UI Library** | React 19 | কম্পোনেন্ট-ভিত্তিক আধুনিক আর্কিটেকচার |
| **Styling** | Tailwind CSS + Soft UI | ক্লিন নিউমরফিজম ও প্রাতিষ্ঠানিক ডিজাইন |
| **Icons** | Lucide React | মডার্ন ভেক্টর আইকন সেট |
| **Database & Auth** | Google Firebase | Firestore নোএসকিউএল ডাটাবেজ এবং ফায়ারবেস অথেন্টিকেশন |
| **Security Standards** | Alibaba OpenCodeReview | জিরো-ইনজেকশন, স্ট্রিক্ট টাইপ ও সুরক্ষিত সেশন হ্যান্ডলিং |

## 🚀 লোকাল সেটআপ ও রান করার নির্দেশিকা (Getting Started)

### ১. ক্লোন করুন
```bash
git clone https://github.com/gitinfobd/recr.git
cd recr
```

### ২. ডিপেন্ডেন্সি ইনস্টল করুন
```bash
npm install
```

### ৩. লোকাল এনভায়রনমেন্ট ভ্যারিয়েবল কনফিগারেশন (`.env.local`)
রুট ডিরেক্টরিতে একটি `.env.local` ফাইল তৈরি করুন:
```env
NEXT_PUBLIC_FIREBASE_API_KEY=your_api_key
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=recr-bd.firebaseapp.com
NEXT_PUBLIC_FIREBASE_PROJECT_ID=recr-bd
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=recr-bd.firebasestorage.app
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
NEXT_PUBLIC_FIREBASE_APP_ID=your_app_id
```

### ৪. ডেভেলপমেন্ট সার্ভার চালু করুন
```bash
npm run dev
```
ব্রাউজারে ভিজিট করুন: [(https://www.freeappweb.com/)

### ৫. প্রোডাকশন বিল্ড
```bash
npm run build
npm start
```

## 🔒 নিরাপত্তা ও অ্যাক্সেস কন্ট্রোল নীতি (Security Guidelines)
1. **জিরো হার্ডকোডেড ক্রেডেনশিয়ালস:** কোনো কোডবেস, গিট কমিট বা কনফিগারেশন ফাইলে পাসওয়ার্ড বা সংবেদনশীল কি (Keys) রাখা সম্পূর্ণ নিষিদ্ধ।
2. **ভূমিকা-ভিত্তিক অথরাইজেশন (RBAC):** শুধুমাত্র অনুমোদিত প্রাতিষ্ঠানিক গুগল অ্যাকাউন্ট বা সুপারএডমিন ক্রেডেনশিয়াল দিয়ে এডমিন কন্ট্রোল প্যানেলে প্রবেশাধিকার কার্যকর।
3. **ডেটা সুরক্ষা ও সততা:** লাইভ প্রাতিষ্ঠানিক ডেটা সুরক্ষার স্বার্থে কোনো অননুমোদিত ড্রপ, ক্লিয়ার বা বাল্ক ডিলিট অপারেশন নিষিদ্ধ।
